## About

This is the personal portfolio of **Prathamesh Anvekar**, an engineer working at the intersection of:

- applied AI and machine learning
- application and model security
- low-level systems programming
- open source and competitive programming

The interface takes structural inspiration from competitive-programming profiles: concise navigation, inspectable work, measurable signals, and a calm technical visual language. It is not a clone of Codeforces and uses no framework or build step.

## What is inside

| Surface | Purpose |
| --- | --- |
| **Profile readout** | A compact first-glance summary of focus, location, education, and current signal |
| **Selected work** | Deep dives into the Secure LLM Proxy Server and Linux Kernel Sandbox |
| **Signals** | Resume-backed measurements from ML, security, and open-source work |
| **Timeline** | Qriocity internship, open-source contributions, and education |
| **Focus mode** | A small interaction that visually quiets the chrome and centers the work |

## Design notes

- Minimal palette: ink, paper, blue, and a single orange signal color
- Typography pairing: `Manrope` for reading and `DM Mono` for data and interface labels
- Hover states use movement and contrast rather than decorative gradients
- Semantic landmarks and visible focus states support keyboard navigation
- `prefers-reduced-motion` is respected
- Responsive layout tested at desktop and narrow mobile widths
- No stock photography, invented testimonials, fake metrics, or generic dashboard cards

## Run locally

No dependencies are required.

```bash
git clone https://github.com/prathamanvekar/tempfolio.git
cd tempfolio
```

Open [`index.html`](./index.html) directly in a browser, or serve the folder with any static file server:

```bash
npx serve .
```
